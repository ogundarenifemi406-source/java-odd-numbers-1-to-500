
# Odd Numbers Between 1 and 500

## Description
This project is a simple Java program that prints all odd numbers between 1 and 500.

## Programming Language
Java

## How It Works
The program uses a for loop starting from 1 and increases the number by 2 in each iteration until it reaches 500.

Since odd numbers increase by 2, the program prints all odd numbers within the specified range.

## Expected Output
Odd numbers between 1 and 500:

1 3 5 7 9 11 13 15 ... 495 497 499

## How to Run
1. Make sure Java is installed.
2. Open the project in a Java-supported editor.
3. Run the Main.java file.
